AR AUTO TRADING — Royal website with vehicle gallery
=====================================================

Upload BOTH files to the root of your GitHub repository:
1. index.html
2. ar-auto-trading-royal-logo.png

iPhone steps:
1. Download and extract this ZIP in Files.
2. Open https://github.com/arautotrading/ar-auto-trading
3. Tap Add file -> Upload files.
4. Select BOTH files above from the extracted folder.
5. Commit changes directly to main.
6. Wait a few minutes, then refresh https://arautotrading.github.io/ar-auto-trading/

Gallery note:
The gallery uses illustrative sample photos loaded from Unsplash. They are not confirmed current stock vehicles. For a real inventory gallery, replace the sample images with your own vehicle photos and update the image filenames/paths in index.html.
